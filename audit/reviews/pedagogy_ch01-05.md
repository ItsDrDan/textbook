# Instructional-quality review, Chapters 1-5 (CHEM 3B textbook), 2026-11-13

Read-only review; no repo file was changed. Scores are 0-4. ACC = scientific accuracy, CLA = conceptual clarity, PRE = prerequisite accessibility, VIS = visual quality (from alt text, captions and placement only; no image was viewed), REA = reasoning transparency, PRA = practice alignment, TRA = transfer. Nothing listed in tools/REVIEW_2026-11-13.md is repeated here.

How it was done: Chapters 1-4 were each read by a separate reviewer agent working from one shared brief; I read Chapter 5 myself, then checked every proposed edit string against the raw HTML by script (each `old` occurs exactly once, each `new` occurs zero times) and spot-checked the claims behind the P1 edits. See (e) for exact coverage.

## Cross-chapter patterns

- **Two-voice pages.** Most section pages are an inherited source text followed by the author's Lecture Connection. The weaknesses cluster in the inherited half: answer-only examples (1.2, 1.3, 1.5, 2.5, 2.8, 3.4), dense sentences (1.7, 2.1, 3.8, 5.5), and outlines that differ from the Lecture Connection's (4.5, 5.4). The Lecture Connection usually does the same job correctly lower on the page.
- **Inherited exercises with no answer.** 4.2 Ex 1-2, 4.4 Ex 1, 4.5 Ex 1, 4.8 Ex 1, 5.1 Ex 1-3 have no inline answer and no key entry (different from the seven print-key pages already in REVIEW). Every author-written exercise has one.
- **Terms used before (or without) definition:** formal charge (1.10 problems only), locant (2.3), resonance / electrophilic / conjugated (3.7), triacylglycerol and polyene (3.2), aliphatic (4.2), Le Chatelier / equilibrium / endothermic (4.4, no CHEM 3A pointer), carbinol carbon (5.4), ester / amide (5.3), "-dial" (5.2).
- **Chapter Guide worked examples without a Check:** 1.9 Ex 2-4, 2.10 Ex 1-4, 3.9 Ex 1-5; 4.11 and 5.6 have them.
- **Pages with no Try It or exercise on the page:** 1.1, 1.2, 1.4, 1.6, 1.7, 2.1, 2.2, 2.4, 2.6, 2.8, 2.9, 3.2, 3.3, 3.6, 3.7, 4.1, 4.6, 4.7 (naming), 4.10 (has exercises, no widget). Not a request for new widgets; where a game mode already exists (noted per chapter) a one-line pointer would do.
- **Clinical/Valley boxes with no question, or a question answerable without chemistry:** 1.2 dental, 2.6 Valley and dental, 3.2 nursing, 3.5 Valley, 3.8 dental, 4.6 both, 4.9 Valley, 5.3 (none), 5.5 nursing and dental. The boxes that do require the chemistry (1.8 tule fog, 2.8 halothane, 3.4 ethylene, 4.5, 5.2 wildfire smoke) are the models.
