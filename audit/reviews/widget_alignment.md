Section scope came from page titles plus the h2-h4 headings of every content page and about 90 keyword greps on specific pages; pages were not read in full.

Classes: ON = tests the widget's stated focus and is teachable by this point; RELATED = same chapter (or same skill family), already taught, not the stated focus; FORWARD = needs a later section (number in the note); OFF = earlier-chapter or unrelated material. Verdict is "tighten" when ON < 70% of the pool or any FORWARD item is present. Chapter Guide / Practice pages are scoped to the whole chapter. Cumulative (fresh=1) rows were only checked at topic level; the FORWARD column there counts items whose own content is later than the chapter.

## Notes on the proposals

- ids= replacements also keep a t= listing only the topic files those ids live in (the widget then loads 1-3 files instead of all 16 and, for a single topic, hides the topic selector); the pool is still exactly the ids.
- Replacements use ids= lists (exact, no incidental matches) even when the list is longer than 25, because q is tested against choices and explanations; I did not search for positive regexes that would reproduce these pools. Trade-off: new bank questions will not join an ids= widget automatically.
- Eight whole-topic chapter-end widgets (4.11, 4.13, 9.7, 9.9 "Lipids", 10.11, 10.13 "Amino acids and proteins", 11.8, 11.10 "Enzymes and vitamins") keep t= and add a negative-lookahead q that drops only the 1-3 forward items; each was verified in Python to yield exactly the intended pool. They rely on stem wording, so rewording those stems would let the items back in.
- No proposed item needs pKa, R/S, E/Z, mechanisms or Km as far as stems and answers show.
- Without a key= parameter the widget derives its storage key from t/q/ids, so changed widgets start with fresh saved progress.
- Every old_src occurs exactly once as an iframe src. On all but 2 pages the same URL also appears once more as the "Open this…" href; replace both. Exceptions with no href copy: 1.8 Intermolecular forces; 3.1 Naming alkenes and alkynes.
