Learning Objectives

  • Identify the general structure for an amine.
  • Identify the functional group for amines.
  • Determine the structural feature that classifies amines as primary, secondary, or tertiary.
  • Use nomenclature systems to name amines.

Amines are classified according to the number of carbon atoms bonded directly to the nitrogen atom. A primary (1°) amine has one alkyl (or aryl) group on the nitrogen atom, a secondary (2°) amine has two, and a tertiary (3°) amine has three (Figure \(\PageIndex{1}\)).

To classify alcohols, we look at the number of carbon atoms bonded to the carbon atom bearing the OH group, not the oxygen atom itself. Thus, although isopropylamine looks similar to isopropyl alcohol, the former is a primary amine, while the latter is a secondary alcohol.

The common names for simple aliphatic amines consist of an alphabetic list of alkyl groups attached to the nitrogen atom, followed by the suffix -amine. (Systematic names are often used by some chemists.) The amino group (NH2) is named as a substituent in more complicated amines, such as those that incorporate other functional groups or in which the alkyl groups cannot be simply named.

Example \(\PageIndex{1}\)

Name and classify each compound.

  1. CH3CH2CH2NH2
  3. CH3CH2NHCH2CH3
  4. CH3CH2CH2NHCH3

Solution

  1. There is only one alkyl group attached to the nitrogen atom, so the amine is primary. A group of three carbon atoms (a propyl group) is attached to the NH2 group through an end carbon atom, so the name is propylamine.
  2. There are two methyl groups and one ethyl group on the nitrogen atom. The compound is ethyldimethylamine (IUPAC name N,N-dimethylethanamine), a tertiary amine.
  3. There are two ethyl groups attached to the nitrogen atom; the amine is secondary, so the compound is diethylamine.
  4. The nitrogen atom has a methyl group and a propyl group, so the compound is methylpropylamine (IUPAC name N-methyl-1-propanamine), a secondary amine.

Ammonium (NH4+) ions, in which one or more hydrogen atoms are replaced with alkyl groups, are named in a manner analogous to that used for simple amines. The alkyl groups are named as substituents, and the parent species is regarded as the NH4+ ion. For example, CH3NH3+ is the methylammonium ion. The ion formed from aniline (C6H5NH3+) is called the anilinium ion.

Example \(\PageIndex{6}\)

Name each ion.

  1. CH3NH3+
  2. (CH3)2NH2+
  3. (CH3)3NH+
  4. (CH3)4N+
Solution

The ions have one, two, three, and four methyl (CH3) groups attached to a nitrogen atom. Their names are as follows:

  1. methylammonium ion
  2. dimethylammonium ion
  3. trimethylammonium ion
  4. tetramethylammonium ion

Lecture Connection

In lecture we start amines with one habit: look at the nitrogen and count the carbon groups bonded directly to it. Everything else in this section (drawing, classifying, and the IUPAC names with the N- locant) builds on that one count.

Classifying amines: count the carbons on N

Professor Tip

Amines are classified differently from alcohols. Look at the nitrogen and count the R groups (carbon groups) bonded directly to N: 1 = 1°, 2 = 2°, 3 = 3°, 4 (with a + charge) = quaternary ammonium ion. (For alcohols, you went to the carbon holding the OH and counted its C–C bonds.) So (CH3)3CNH2 is a primary amine even though its carbon is tertiary. Quaternary means four bonds to N: that is an ammonium ion, not a fourth kind of amine.

Drawing amines. In a line (skeletal) structure the hydrogen atoms on nitrogen must be shown (NH2, NH), because that is how you tell a 1° amine from a 2° or 3° one. In a condensed structure, identical groups on N can be grouped: CH3CH2NHCH2CH3 is also written (CH3CH2)2NH, and a group branching off the nitrogen of a 3° amine goes in parentheses after the N: CH3CH2CH2N(CH3)CH2CH3 has a methyl on N between a propyl and an ethyl group. Practice: draw the line-angle structure of that last compound and confirm it is a 3° amine.

IUPAC names: the N- locant

  • Common names: list the alkyl groups alphabetically + "amine", written as one word: ethylmethylamine, triethylamine.
  • IUPAC, 1° amines: find the longest carbon chain that contains the carbon holding the NH2, change the -e of the alkane to -amine, number so that N gets the lowest locant, then apply all the other nomenclature rules: 1-propanamine, 2-butanamine.
  • IUPAC, 2° and 3° amines: the longest alkyl chain bonded to N is the parent amine; every other group on the nitrogen is named as N-alkyl (the locant N says "this is on the nitrogen"), listed alphabetically if there is more than one: N-methylethanamine, N,N-dimethyl-1-propanamine, N-ethyl-N-methylcyclohexanamine.
  • More than one functional group: an acid, aldehyde, ketone, or alcohol outranks an amine, so when one of those is present the NH2 becomes the substituent amino- and the parent keeps its own suffix: 2-aminoethanol, 4-aminobutanoic acid, 4-amino-2-pentanone. The amine is the parent only when nothing of higher priority is present; halogens and alkyl groups are always substituents (3-chloro-N-methyl-1-butanamine). Example 4 in the Chapter Guide works through the choice.

Professor Tip

On exams, use IUPAC names: when the amine is the highest-priority group it is the parent and takes the -amine suffix (3-methyl-2-pentanamine), and groups on the nitrogen carry the locant N. Use amino- only when an alcohol, ketone, aldehyde, or carboxylic acid outranks the amine. You should still recognize the common names.

Aniline derivatives

C6H5NH2 is aniline, and the IUPAC system keeps that name for any amine whose N is bonded directly to a benzene ring. Groups on the nitrogen get N- (C6H5NHCH3 is N-methylaniline); groups on the ring get numbers, with the NH2 carbon as C1, or the o/m/p prefixes for a disubstituted ring (4-chloroaniline = p-chloroaniline).

Example 1: Name and classify a substituted aniline

Problem. Name and classify a benzene ring with NH2 on C1 and Cl on C3.

Solution. The parent is aniline; the chlorine is on ring carbon 3, so the name is 3-chloroaniline (m-chloroaniline). The nitrogen carries one carbon (the ring), so it is a 1° aromatic amine.

Check. A number on the ring, not N, because the Cl is on carbon. 4-Methylaniline has CH3 on the ring; N-methylaniline has CH3 on the nitrogen. They are different compounds.
