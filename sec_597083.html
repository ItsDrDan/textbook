Lecture Connection

The source gives alkynes a paragraph; lecture gives them the same naming rules as alkenes with one new ending and one new shape. Learn them as a footnote to alkenes: -yne, general formula CnH2n−2, and a linear triple bond.

Alkyne naming and shape

  • Pick the longest chain that contains the C≡C, number so the triple bond gets the lowest number, and change the ending to -yne: HC≡CCH2CH3 is 1-butyne; CH3C≡CCH3 is 2-butyne. If the triple bond is the same distance from both ends, start at the end nearer the first branch.
  • The two carbons of a triple bond have two electron groups each, so they are linear (180°). In a line structure draw the C≡C and its two neighboring atoms in a straight line; a bent alkyne is a drawing error.
  • Because the two alkyne carbons each carry only one other group, alkynes never have cis/trans isomers.
  • Alkynes undergo the same addition reactions as alkenes, twice over. One mole of H2 (Pt) turns an alkyne into an alkene; a second mole gives the alkane: 2-butyne + 2 H2 → butane. Combustion gives CO2 and H2O as always.

Common name to recognize: acetylene is ethyne, the welding gas. Write "ethyne" on an exam.

Example 1: Naming a cycloalkene and an alkyne

Problem. (a) A cyclohexene ring carries a CH3 group on the carbon next to one of the double-bond carbons. Name it. (b) Name CH3CH2C≡CCH(CH3)CH3.

Solution. (a) In a ring the double bond is always C1–C2, so the only decision is which direction to number. Going from C1 through the double bond to C2 and on toward the methyl puts it on C3; going the other way around the ring would put it on C6. Lowest number wins: 3-methylcyclohexene. (b) The longest chain containing the triple bond has 6 carbons. From the left the triple bond starts at C3; from the right it also starts at C3, so use the branch to break the tie: from the right the methyl is on C2, from the left it would be C5. Name: 2-methyl-3-hexyne.

Check. In (a) the name has no number for the double bond, which is correct for a ring; "6-methylcyclohexene" would be the same molecule numbered the wrong way. In (b) count hydrogens: C7H12 fits CnH2n−2 for an alkyne with 7 carbons (6 in the chain plus the methyl).
