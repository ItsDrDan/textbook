# Faculty reviewer form: CHEM 3B open textbook

Thank you for reviewing. Pick one or more chapters in the sign-up table, read them as you would before assigning them, and fill in the rubric and the corrections table. One chapter takes about 1–2 hours. Return the form to Daniel Kwasniewski (daniel.kwasniewski@fresnocitycollege.edu), or post corrections at github.com/ItsDrDan/textbook/issues.

The ten criteria are the ones the Open Textbook Library asks its faculty reviewers to use, so these reviews can also support a listing there.

**Book:** *Introductory Organic and Biological Chemistry for FCC*, https://chem.libretexts.org/@go/page/488223 (no login needed). Use the table of contents to move between sections: while the book is in the LibreTexts Workbench, the Previous/Next arrows can point to another college's book.
**Course outline:** CHEM 3B COR, effective Spring 2027 (C-ID CHEM 102). The *Course Outline Alignment* page maps every outline item to its sections; *For Instructors* lists the conventions the book uses.

## Rubric

Rate each criterion 1–5 (5 = excellent, 3 = adequate, 1 = not usable) for the chapters you read, and add a sentence or two. Comments help more than numbers.

| # | Criterion | What to look for | Rating | Comments |
|---|---|---|---|---|
| 1 | Comprehensiveness | Covers the COR topics for these chapters at the depth CHEM 3B tests; the Chapter Guide, reaction tables and Practice Problems are complete. | | |
| 2 | Content accuracy | Structures, names, reactions, pathway steps, ATP counts and clinical values are correct; answers to exercises and practice problems are right; cited numbers match their sources. | | |
| 3 | Relevance and longevity | Clinical boxes, the Rosa case, Valley Connections and In the Lab boxes fit our students and will not date quickly; updates would be easy. | | |
| 4 | Clarity | Prose is clear for students at this level; new terms are defined when first used; worked examples show every step. | | |
| 5 | Consistency | Terms and conventions ([H]/[O], 2.5/1.5 ATP, enzyme classes, acid-strength ranking, naming) are the same throughout and match how we teach. | | |
| 6 | Modularity | Sections can be assigned on their own or in a different order without confusing students. | | |
| 7 | Organization and flow | Topics build in a logical order; prerequisites (Chapter 1 review, functional groups) come before they are needed; cross-references point to the right sections. | | |
| 8 | Interface | Pages, figures, tables, Answer buttons, Try It boxes, game labs and videos work and are easy to use, on a phone and in the PDF. | | |
| 9 | Grammar and mechanics | No spelling, grammar or formatting errors that distract. | | |
| 10 | Cultural relevance and inclusion | Examples, names and contexts are inclusive and respectful; nothing is insensitive or offensive. | | |
