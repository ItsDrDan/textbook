# Review and OER listing packet: CHEM 3B (2026-11-20)

Everything needed to (1) get the book approved by the FCC Chemistry Department as the CHEM 3B OER, (2) collect structured faculty reviews, and (3) list the book in OER catalogs once it is approved. Same structure as the CHEM 3A packet (`github/CHEM3Atextbook/review/`).

| File | Who it is for | What it does |
|---|---|---|
| [01_DEPARTMENT_SUMMARY.md](01_DEPARTMENT_SUMMARY.md) | Chemistry Department (chair and CHEM 3B faculty) | Two-page case for approval: what the book is, outline coverage, features, cost, licensing, accessibility, and what is still open. |
| [02_REVIEWER_FORM.md](02_REVIEWER_FORM.md) | Each faculty reviewer | The ten Open Textbook Library criteria as a rubric, a chapter sign-up table so reviewers can split the 15 chapters, and a corrections table. |
| [03_OER_LISTING.md](03_OER_LISTING.md) | Dr. Kwasniewski, after approval | Ready-to-paste catalog text, where to list it, and the release checklist. |

**Status:** drafts for Dr. Kwasniewski to read and edit. Nothing here has been sent or posted.
