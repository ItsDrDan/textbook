## Lecture-slide figures (`Slide*.png`)

The audit flagged nine slide figures (Slide35, 38, 40, 41, 43, 50, 68, 69, 70) because the decks follow Timberlake's chapter order and some figures resembled textbook art. On 2026-11-11 the author confirmed drawing all of the slide figures, so they are credited as the author's own work under the book's CC BY 4.0 license.

Corrections made on 2026-11-11 (same file names, so the book updates automatically):
- **Slide2:** "Normal branched chain" changed to "Normal (unbranched) chain" (twice), and "Isometric shape" to "Iso shape".
- **Slide15:** the Tollens equation is now balanced: CH₃CHO + 2Ag⁺ + 3OH⁻ → CH₃COO⁻ + 2Ag + 2H₂O. Before, the right side had acetic acid + 2Ag + H₂O, which balanced neither atoms nor charge.
- **Slide28:** "three-caron" changed to "three-carbon".
- **Slide42:** removed the stray "H–" on the ketose carbon, which had given it five bonds. It now reads CH₂OH–C(=O)–.
- **Slide43:** removed leftover "O"/"OH" glyph fragments at the lower left. The comparison fructose ring is kept.
- **Slide49:** 3 H₂O changed to 3 NaOH in both saponification equations. The arrow keeps "Heat".
- **Slide68:** cut-off labels completed ("Maximum rate", "Optimum pH"). The image is 70 px wider.

The alt text on LibreTexts for Slide15, Slide42 and Slide49 still describes the old versions; see the PR TODO for replacement text.
